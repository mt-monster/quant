# 三阶Alpha生成Pipeline - 命令使用说明

## 概述

Pipeline是一个专业的三阶Alpha因子生成系统，基于WorldQuant BRAIN平台API设计，支持从原始数据字段到可提交Alpha的全流程自动化生成。

## 前置条件

1. **环境配置**
   - Python 3.8+
   - 安装依赖：`pip install pyyaml click`
   - 配置WorldQuant API凭据（`.env` 文件）

2. **工作目录**
   ```bash
   cd worldquant_alpha
   ```

## 命令详解

### 1. 运行Pipeline (`run`)

运行完整的三阶Alpha生成流程。

**语法：**
```bash
python -m main third-order run [选项]
```

**选项：**

| 选项 | 简写 | 说明 | 默认值 |
|------|------|------|--------|
| `--config` | `-c` | 配置文件名或路径 | `third_order_default.yaml` |
| `--from-stage` | - | 从指定阶段开始 | 从头开始 |
| `--to-stage` | - | 执行到指定阶段结束 | 运行到最后 |
| `--force` | - | 强制重新运行已完成的阶段 | `false` |
| `--state-file` | - | 状态文件路径 | `.pipeline_state.json` |

**可用阶段列表：**
- `first_order` - 一阶Alpha生成
- `first_order_backtest` - 一阶回测
- `first_order_filter` - 一阶筛选
- `second_order` - 二阶Alpha生成
- `second_order_backtest` - 二阶回测
- `second_order_filter` - 二阶筛选
- `third_order` - 三阶Alpha生成
- `third_order_backtest` - 三阶回测
- `third_order_filter` - 三阶筛选

**使用示例：**

```bash
# 使用默认配置运行完整Pipeline
python -m main third-order run

# 使用指定配置文件
python -m main third-order run --config third_order_aggressive.yaml

# 从二阶生成开始执行
python -m main third-order run --from-stage second_order

# 只运行到一阶筛选结束
python -m main third-order run --to-stage first_order_filter

# 指定起始和结束阶段
python -m main third-order run --from-stage second_order --to-stage third_order_filter

# 强制重新运行所有阶段
python -m main third-order run --force

# 使用自定义状态文件
python -m main third-order run --state-file my_state.json
```

## 配置文件

### 预设配置

| 配置文件 | 策略类型 | Sharpe阈值 | 特点 |
|----------|----------|------------|------|
| `third_order_default.yaml` | 平衡模式 | 0.7/1.0/1.25 | 标准配置，适合大多数场景 |
| `third_order_aggressive.yaml` | 激进模式 | 0.5/0.7/1.0 | 更多Alpha，探索性强 |
| `third_order_conservative.yaml` | 保守模式 | 1.0/1.25/1.5 | 高质量，稳健策略 |

### 配置文件结构

```yaml
pipeline:
  name: "三阶Alpha生成Pipeline"
  version: "2.0"

  # 全局设置
  settings:
    region: "USA"           # 地区
    universe: "TOP3000"     # 股票池
    instrument_type: "EQUITY"
    delay: 1

  # 数据配置
  data:
    datasets: ["fundamental6", "mdl110"]
    preprocessing:
      backfill_days: 120
      winsorize_std: 4

  # 阶段配置
  stages:
    first_order:
      enabled: true
      operations: [ts_rank, ts_zscore, ts_mean, ts_std_dev]
      time_windows: [5, 22, 66, 120, 240]

    first_order_filter:
      sharpe_threshold: 0.7
      fitness_threshold: 0.5
      prune_keep_per_field: 3

    second_order:
      enabled: true
      group_operations: [group_rank, group_neutralize, group_zscore]

    # ... 更多配置

  # 回测配置
  backtest:
    mode: "concurrent"      # concurrent | sequential
    max_workers: 4
    batch_size: 10
    rate_limit_delay: 1.0
```

## 三阶生成流程

### 阶段1: 一阶生成 (First Order)

**输入：** 预处理后的数据字段

**操作：** 时间序列操作 `ts_ops(field, days)`

**支持的操作符：**
- `ts_rank` - 时间序列排名
- `ts_zscore` - 时间序列Z分数
- `ts_mean` - 时间序列均值
- `ts_std_dev` - 时间序列标准差
- `ts_delta` - 时间序列差分
- `ts_sum` - 时间序列求和
- `ts_product` - 时间序列乘积
- `ts_min` - 时间序列最小值
- `ts_max` - 时间序列最大值
- `ts_skewness` - 时间序列偏度
- `ts_kurtosis` - 时间序列峰度

**输出：** 一阶Alpha表达式列表

**示例：**
```
ts_rank(winsorize(ts_backfill(close, 120), std=4), 5)
ts_zscore(winsorize(ts_backfill(volume, 120), std=4), 22)
```

---

### 阶段2: 二阶生成 (Second Order)

**输入：** 一阶筛选结果

**操作：** 分组操作 `group_ops(first_order_expr, group)`

**支持的操作符：**
- `group_rank` - 分组排名
- `group_neutralize` - 分组中性化
- `group_zscore` - 分组Z分数
- `group_scale` - 分组缩放

**支持的分组：**
- `sector` - 行业板块
- `industry` - 产业
- `subindustry` - 子产业
- `market` - 市场

**输出：** 二阶Alpha表达式列表

**示例：**
```
group_neutralize(ts_rank(winsorize(ts_backfill(close, 120), std=4), 5), sector)
group_zscore(ts_zscore(winsorize(ts_backfill(volume, 120), std=4), 22), industry)
```

---

### 阶段3: 三阶生成 (Third Order)

**输入：** 二阶筛选结果

**操作：** 事件触发 `trade_when(entry_event, alpha_expr, exit_event)`

**开仓事件 (Entry Events)：**
- `ts_arg_max(volume, N) == 0` - 成交量突破
- `ts_corr(close, volume, N) < X` - 价格-成交量相关性
- `ts_std_dev(returns, N) > X` - 波动率突破

**平仓事件 (Exit Events)：**
- `abs(returns) > X` - 收益达到阈值
- `ts_arg_max(abs(returns), N) < M` - 持有期满
- `-1` - 永不平仓

**输出：** 三阶Alpha表达式列表

**示例：**
```
trade_when(ts_arg_max(volume, 5) == 0, group_neutralize(...), abs(returns) > 0.1)
trade_when(ts_corr(close, volume, 20) < 0, group_zscore(...), -1)
```

## 故障排除

### 问题1: API登录失败

**错误信息：** `WorldQuant平台登录失败`

**解决方案：**
1. 检查 `.env` 文件中的API凭据
2. 确认网络连接正常
3. 验证API密钥是否有效

### 问题2: API限流

**错误信息：** `APIError: 429 Too Many Requests`

**解决方案：**
1. 降低并发数：修改配置中的 `max_workers`
2. 增加限流延迟：修改 `rate_limit_delay`
3. 使用单线程模式：设置 `mode: sequential`

### 问题3: 内存不足

**错误信息：** `MemoryError`

**解决方案：**
1. 减少批处理大小：修改 `batch_size`
2. 降低剪枝数量：修改 `prune_keep_per_field`
3. 分阶段运行

### 问题4: 配置验证失败

**错误信息：** `ValidationError`

**解决方案：**
1. 检查YAML语法
2. 确认必需字段完整
3. 验证参数值类型

### 问题5: 状态文件损坏

**错误信息：** `JSONDecodeError` 或状态异常

**解决方案：**
```bash
# 重置状态
python -m main third-order reset

# 重新运行
python -m main third-order run
```

## 性能优化建议

| 参数 | 说明 | 建议值 |
|------|------|--------|
| `max_workers` | 并发线程数 | 4-6 |
| `batch_size` | 批处理大小 | 10-20 |
| `rate_limit_delay` | 限流延迟（秒） | 1.0-2.0 |
| `backfill_days` | 回填天数 | 120 |
| `winsorize_std` | 缩尾标准差 | 4 |
